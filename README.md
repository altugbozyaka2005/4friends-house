# 4 Friends House — concept website

Concept single-page website for **4 Friends House**, a 9-room Georgian guest house at 106 Ferry Road, Leith, Edinburgh.

- Room showcase for all 8 room types, with photo sliders and detail pop-ups
- Direct-booking flow (dates, room, rate, promo code) that hands off to the house's existing Cloudbeds booking engine for secure payment
- Gallery, amenities, guest reviews, map and FAQ

Open `index.html` in a browser (needs an internet connection for photos and fonts).

> Concept preview — not the official website of 4 Friends House.
